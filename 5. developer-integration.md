# 🧰 Developer Integration

SynLedger is **developer-first**, offering a full suite of APIs, SDKs, and smart contracts.

---

## 🪙 SDKs
- **JavaScript / TypeScript SDK**
- **Solidity interfaces**
- **RESTful API endpoints**
- **Webhook notifications**

---

## 🔧 Core API Actions

| Endpoint | Action |
|-----------|--------|
| `POST /escrows` | Create new escrow |
| `POST /escrows/:id/fund` | Deposit stablecoins |
| `POST /escrows/:id/release` | Trigger fund release |
| `POST /escrows/:id/dispute` | Raise dispute flag |
| `GET /escrows/:id` | Fetch escrow details |

---

## 🧩 Integration Scenarios

- **Freelance platforms:** plug escrow contracts into gig workflows.  
- **DAOs:** automate payouts based on proposals or votes.  
- **Marketplaces:** handle buyer-seller disputes natively.
