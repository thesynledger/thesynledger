# SynLedger Website (Vanilla) — V2
A more polished, modern landing + founders page with glassmorphism, gradients, and subtle motion.

## Deploy on GitHub Pages
1. Create a public repo.
2. Upload the files at the repo root.
3. Settings → Pages → Source: `main` branch (root).
4. Update `script.js`:
   - `DOCS_URL` → your docs path or GitBook URL.
   - `GITHUB_URL` → your repository URL.
5. Push. Done.

## Notes
- Fully **vanilla** (no frameworks).
- **Light/Dark** toggle persists.
- Subtle **reveal on scroll** (respects reduced-motion).
- Edit colors in `:root` CSS variables.
