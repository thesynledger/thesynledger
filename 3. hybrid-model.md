# The Hybrid Escrow Model

SynLedger introduces **configurable escrow logic** that blends human judgment and oracle automation.

---

## Modes of Operation

| Mode | Description | Use Case |
|------|--------------|----------|
| **Multi-Sig Approval** | Funds released when all signers approve. | Freelance contracts |
| **Oracle Auto-Release** | Oracle confirms completion and releases funds. | DAO bounties, SLA payments |
| **Hybrid / Fallback** | Auto-release by oracle, revert to manual multi-sig if needed. | Marketplaces, subscriptions |

---

## Why Hybrid?

- **Flexibility:** Adjusts to deal complexity.
- **Reliability:** Oracle + human safety net.
- **Scalability:** One protocol, multiple flows.

> **Hybrid = Trust and Automation in Harmony**
